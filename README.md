# 🎵 Music Player App

**Description:**  
A Java-based music player application with **Firebase cloud integration** that allows users to play, pause, and manage audio files both locally and from the cloud.  
The app synchronizes songs stored in Firebase with tracks available on the device, providing a seamless listening experience and demonstrating secure data handling practices for cloud-connected applications.

---

## ⚙️ Features
- 🎧 Play, pause, skip, and repeat songs from local storage or Firebase Cloud  
- ☁️ Upload and stream music files using Firebase Realtime Database & Storage  
- 🧩 Dynamic playlist management with track metadata and album info  
- 🖥️ Simple, responsive JavaFX interface  

---

## 🧠 Tech Stack
- **Language:** Java  
- **Framework:** JavaFX  
- **Cloud Platform:** Firebase (Realtime Database & Cloud Storage)  
  

---

## 🔐 Security Considerations
- Implemented **Firebase authentication** for secure data access  
- Applied basic **input validation and exception handling** in the app
